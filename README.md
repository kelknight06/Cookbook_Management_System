# Software-Engineering-Project:  Cookbook Management and Tracking System
## Kel Knight & Melissa Weitekamp

A repository for this project that is about a cookbook management software with the aim to satisfy anyone with a passion for cooking and an exhaustion of paragraphs in other recipe forums. The software will allow users to perform recipe tracking, follow a step-by-step instruction checklist, and maintain an ingredient inventory. Users will be able to personalize the recipes to their own discretion through modifications to recipes on their end. The ingredient inventory will act as a pantry to see if a user can make a recipe, and also can be used for match making to suggest any other recipes they could make with what they have. A filtration will permit users to sort recipes by breakfast, appetizers, entrées, and desserts. The Cookbook Management system will parse online recipe blogs and websites to strengthen the database. An OCR Photo Scanning tool will be implemented as well to allow for the scanning and digitization of handwritten recipes. That feature will also be user specific and not for all users of the system to view. Another feature of the system is the scaling translator that will assist users in scaling based on the ingredient quantity. The UI will change depending on if the user is in a cooking mode, or browsing mode. With this, the UI will adapt to screen dimensions regardless of the mode to allow for easy access on desktop and mobile devices.
